Project Explorer for the opencode TUI

Cairn (n.) — a small pile of stones that marks the trail. This plugin marks yours through the codebase. Colorful, collapsible file tree beside the MCP section.

Core features

Small, fast, persistent

  • Persistent tree, per-folder ▸/▾ + ├── / └── guides
  • Color-coded: folders sky-blue, ts blue, js yellow, json/yaml green, md purple, html/css orange, media pink, configs gray
  • Click folder to toggle, click file to open via OS (start / open / xdg-open)
  • Keyboard + palette guaranteed over SSH; mouse best-effort
  • Auto-shows on launch, state in cairn.params survives restarts
  • Skips node_modules .git dist graphify-out • depth 1–10, default 3
How it works

Two files

index.ts — cairn.serverServer stub. Plugin.define(id only).
tui.tsx — cairn.clisidebar.content slot renders tree; app slot registers keymap, slash + palette.
slots: sidebar.content → tree (34ch, pure render)
       app → commands (/cairn*, Cairn: *)
store: cairn.params { visible, root, depth, paneCollapsed, expanded[], selected }
Commands + config

Palette-first

/cairn ............ toggle panel
/cairn expand|collapse
/cairn toggle <path> • pick
/cairn next|prev • edit [path]
/cairn all|all collapse
/cairn src 2 • reset • help
visible=true  • auto-show
root="" (= project)
depth=3 (1-10)
paneCollapsed=false
expanded=top dirs
selected=""
Install • 30 seconds

Copy, restart, done

# Windows
Copy-Item -Recurse ./opencode-cairn "$env:USERPROFILE/.config/opencode/plugins/opencode-cairn"
# macOS / Linux
cp -r ./opencode-cairn ~/.config/opencode/plugins/opencode-cairn
# verify
opencode --print-logs plugin list  # → cairn.server local ...

Uninstall: delete folder + restart. No build, no bun install.
