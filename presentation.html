PRESENTER GUIDE opencode-cairn talk track

How to present this plugin in 3 minutes

Cover (cairn metaphor) → Problem → Visuals (both PNGs) → Features → How it works (2 files) → Commands → Install → Roadmap. All styles, buttons, animations, theme, HUD, progress, modal, and PDF export come from the boilerplate engine.

1. Adding New Slides:

Add another <section class="slide" id="slide-N" data-slide-title="...">. JavaScript automatically calculates the total slide count, updates HUD indicators, and builds segmented progress bars.

2. Staggered Entrance Animations:

Add data-animate="1" through data-animate="5" to elements. The orchestrator reveals each sequentially on slide entry.

3. Theme System & Shortcuts:

Toggle between Dark (Obsidian Gold) and Light (Architectural Studio Off-White) by clicking any theme button or pressing T.

4. PDF Presentation Export:

Click the PDF button in the top bar or floating HUD, or press P. The engine renders all slides concurrently across clean landscape printable pages.
